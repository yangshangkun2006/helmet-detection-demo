安全帽检测 · 本地演示界面
========================================

【怎么启动】
双击 start_demo.bat，浏览器会自动打开 http://127.0.0.1:8765
（如果没自动打开，手动在浏览器输入这个地址）
停止服务：在黑色命令行窗口里按 Ctrl+C，或直接关掉窗口。

【怎么演示】
1. 左侧拖拽一张照片进去，或点击「选择图片」，也可以直接点三张示例图之一。
2. 拖动「置信度阈值」滑块（默认 0.35；误报多调高，漏检多调低）。
3. 点「开始检测」，右侧会显示带检测框的结果图、戴帽/未戴帽数量和框明细。
4. 检测到未戴帽时会出现红色告警提示。

【目录说明】
app.py         Web 服务 + YOLO 推理后端（只用了 Python 标准库，不需 Flask）
index.html     深色演示界面
best.pt        之前训练好的模型权重（与云端版本 SHA256 一致）
samples/       三张公开数据集原始示例图
uploads/       你上传的图片
results/       每次检测生成的带框图
run_demo.py    一键启动器：自动找带 ultralytics 的 Python 并打开浏览器
start_demo.bat 双击启动入口

【环境说明】
使用本机 DeepLearning 程序自带的 pt128 环境推理（torch CPU + ultralytics 8.4.71），
不需要重新安装依赖，也不需要 GPU。推理一张 640×640 图约 0.3 秒。
若 8765 端口被占用，可在命令行先执行 set HELMET_DEMO_PORT=8766 再启动。

【边界】
这是 400 张公开子集训练的教学模型，mAP50 ≈ 0.81，仅用于流程演示；
不能用于现场安全合规判定。模型只识别「人头是否有帽」，不识别作业区域，
办公室/教室里的人也会触发告警。要落地需加作业区 ROI、连续帧确认，
并用真实工地图片补充标注后重新训练。
