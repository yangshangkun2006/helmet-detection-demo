六、怎么用
============================================================
云端 GPU（最快，无需另装东西）：
  cd /workspace
  /workspace/yolo26-rocm-day1-labs/.venv/bin/python use_helmet_model.py \
      --weights /workspace/helmet_runs/baseline/weights/best.pt \
      --source /workspace/helmet_data/images/demo --conf 0.35 --save

本机 Windows（普通电脑即可，不需要 GPU）：
  pip install ultralytics          # 会带 CPU 版 torch，几百 MB
  python use_helmet_model.py --weights best.pt --source 你的照片.jpg --save
  python use_helmet_model.py --weights best.pt --source 图片目录/ --conf 0.5
  python use_helmet_model.py --weights best.pt --source 视频.mp4 --save
  python use_helmet_model.py --weights best.pt --source 0   # 本机摄像头，Ctrl+C 退出

  --conf 是最顺手的旋钮：误报多调高（0.35 -> 0.5），漏检多调低。
  「发现违规后做什么」是脚本里 if n_violation: 之后你自己的业务代码
  （写 CSV / 存截图 / 推消息 / 亮灯），模型只负责输出框和置信度。

复现（换实例后）：
  把 Day1/helmet/ 下 4 个脚本推到云端 /workspace，备好
  /workspace/helmet_src/{train,valid,test}.zip 及 Day1 的 .venv、yolo26n.pt，然后
  cd /workspace && setsid nohup bash run_helmet.sh > helmet_run.log 2>&1 < /dev/null &
  注意：外层代理对单条 SSH 流有约 1MB 上限，取回 best.pt 需分 512KB 块传输。

============================================================
七、必须知道的边界
============================================================
1. 这是 400 张公开子集 / 30 epoch 的教学练习模型，mAP50 0.8115 只是该子集上的数字。
   换工地、光照、摄像头角度都会掉，不能真拿去做现场安全合规判定。
2. no_hardhat 标注的是「没戴帽的人头」，不是完整人体。要判定「这个人到底戴没戴」，
   要么在下游写 head/helmet 框的配对规则，要么改训 with_helmet / without_helmet 两类。
3. 许可：数据集与 Ultralytics（AGPL-3.0 / Enterprise 双许可）用于学习研究没问题，
   商用前需核对条款。
4. 本次训练约消耗 6 分钟 GPU 时长；实例不用时记得销毁，否则持续计时。
